# Шёпот — анонимные истории

Небольшой адаптивный прототип пространства для коротких анонимных историй.

## Идея

«Шёпот» — не ещё одна соцсеть с профилями и подписчиками. Это тихая лента, где важны слова, а не автор. Пользователь может поделиться короткой мыслью, выбрать тему дня, прочитать истории других людей и поддержать их реакцией.

## Возможности прототипа

- Публикация коротких историй (до 500 символов)
- Лента с фильтрами: «Мысли», «Радость», «Поддержка»
- Реакция поддержки
- Тема дня с быстрым переходом к форме публикации
- Кнопка жалобы (пока демонстрационная)
- Адаптивный интерфейс для телефона и компьютера
- Данные демо сохраняются в localStorage текущего браузера

## Запуск

Это статический прототип: откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория.

## Важно перед публичным запуском

Сейчас публикации не отправляются на сервер и видны только в том браузере, где были созданы. Для настоящего многопользовательского сервиса понадобятся backend и база данных, серверная модерация, rate limiting, защита от спама, политика конфиденциальности и понятный процесс обработки жалоб. Не обещайте пользователям абсолютную анонимность: технические журналы и инфраструктура могут обрабатывать сетевые данные.

Для безопасного сообщества стоит исключить личные сообщения и геолокацию на первом этапе, не собирать лишние персональные данные и предусмотреть модерацию до публикации потенциально вредного контента.
