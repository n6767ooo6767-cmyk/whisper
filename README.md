# Шёпот — анонимные истории

«Шёпот» — небольшая адаптивная лента коротких историй без публичных профилей.

## Возможности

- Публикация историй до 500 символов
- Фильтры «Мысли», «Радость», «Поддержка»
- Реакции поддержки
- Тема дня
- Серверное хранение: каждая история автоматически записывается в отдельный JSON-файл
- Автоматическое создание папки `data/stories` и стартовых JSON-записей при первом запуске

## Запуск локально

Нужен Node.js 18 или новее. В корне проекта:

```bash
npm start
```

Откройте http://localhost:3000. При первом старте сервер сам создаст `data/stories/` и несколько демонстрационных файлов. Новая история сохраняется как отдельный файл с уникальным ID, например `data/stories/<id>.json`.

## API

- `GET /api/stories` — получить все истории
- `POST /api/stories` — создать историю (JSON: `{"text":"...","tag":"Мысли"}`)
- `POST /api/stories/:id/like` — добавить реакцию

## Важно для деплоя

Это файловое хранилище для небольшого прототипа, не полноценная production-база. Сервер должен запускаться в среде Node.js; GitHub Pages не запускает Node-сервер и не может записывать файлы в репозиторий. На хостинге с эфемерной файловой системой истории могут исчезнуть при перезапуске или новом деплое — подключите постоянный диск и храните `data/stories` на нём. Для публичного запуска также нужны модерация, защита от спама и злоупотреблений, ограничение частоты запросов, резервное копирование и политика конфиденциальности. Не обещайте абсолютную анонимность: инфраструктура хостинга может обрабатывать сетевые данные.

Не добавляйте в истории личные данные, адреса, телефоны или ссылки на личные аккаунты.
