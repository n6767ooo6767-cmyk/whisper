# Шёпот — анонимные истории

Небольшое приложение на **HTML, CSS, JavaScript и Vue 3**. Работает как статический сайт на GitHub Pages — Node.js и сборка не нужны.

## Возможности

- Лента историй из `stories.json`
- Публикация своих историй до 500 символов
- Фильтры «Мысли», «Радость», «Поддержка»
- Реакции поддержки
- Адаптивный интерфейс

## Как запустить

Открой сайт через GitHub Pages или запусти локальный статический сервер (например, расширение Live Server в VS Code). Для загрузки `stories.json` не открывай HTML через `file://` — браузер может заблокировать fetch.

## Как устроено хранение

- `stories.json` — начальные истории, которые загружаются для всех посетителей. GitHub Pages отдаёт этот файл только для чтения.
- `localStorage` — новые истории и реакции сохраняются локально в браузере конкретного посетителя.
- Браузерный JavaScript не может автоматически создавать и коммитить JSON-файлы в GitHub-репозиторий. Для общей записи историй от разных пользователей потребуется backend или отдельный сервис хранения.

Vue 3 подключается через CDN, поэтому npm, Node.js и этап сборки не требуются.
